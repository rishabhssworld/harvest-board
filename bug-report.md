| 1   | The page showed “Cannot read properties of null” when the script tried to add a listener. | volunteer.html:8       | The script ran before the form was available in the page.     | Added `defer` to the script tag.               |

| 6   | `<b>Ana</b>` appeared as bold Ana instead of literal text.                                | volunteer.js:16        | `innerHTML` interpreted the visitor’s name as HTML.           | Used `textContent` to display the name safely. |
